# Stock Portfolio Tracker

A simple Python program that calculates the total investment based on the selected stock and quantity.

## Features

* Stores stock prices using a dictionary
* Takes stock name and quantity as input
* Calculates total investment
* Displays the stock price and total investment
* Shows a message if the stock is not found

## Concepts Used

* Dictionary
* User input
* If-else statements
* Variables
* Arithmetic operations

## How to Run

Run the Python file in VS Code or any Python environment and enter the stock name and quantity when prompted.
