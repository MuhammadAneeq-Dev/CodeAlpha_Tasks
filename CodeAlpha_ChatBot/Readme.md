# Chatbot

A simple Python-based chatbot that interacts with the user through the console.

## Features

* Responds to hi or hello.
* Responds to how are you.
* Says goodbye when the user enters bye.
* Handles unknown inputs with a default response

## Concepts Used

* Functions
* While loop
* If-elif-else statements
* User input
* String methods

## How to Run

Run the Python file in VS Code or any Python environment and enter your messages in the console.
