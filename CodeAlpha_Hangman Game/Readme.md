# Hangman Game

## Description
This is a simple text-based Hangman Game developed using Python. The player has to guess the hidden word by entering one letter at a time.

## Features
- Random word selection
- Letter guessing system
- Limited number of incorrect attempts
- Displays guessed letters
- Simple command-line interface

## Concepts Used
- Python
- Lists
- Loops
- Conditional Statements
- Functions
- User Input
- Random Module
- String Handling

## How to Run
1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Run the following command:

python hangman.py
